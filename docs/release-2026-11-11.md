## For people with the app installed

- **Terms version 2026-11-10.** Everyone is asked to agree once more. Older
  builds send the text they carry in the `X-Ascendra-Legal` header, so they
  can accept their own text without a loop.
- **New accounts need an updated app.** Builds from before this release
  have no 16-or-older checkbox, so the server refuses a new account from
  them. Existing accounts are unaffected.
- **Paced sims need an updated app.** An open run on the new tamponade
  version is not handed to an older app (409 `app_update_required`).
