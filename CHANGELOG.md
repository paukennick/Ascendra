# Changelog

## Unreleased

- REQ-022: Opened the nursing strand of the catalog. Added Healthcare & Nursing as a fourteenth top-level category with ten subcategories, since the existing taxonomy's nearest fit for licensure was Health & Fitness alongside yoga and dance. Widened credential records so a qualification governed by an accreditation standard or a state licence -- rather than a vendor exam code -- can be recorded and kept fresh. Seeded the NCLEX-RN course from the NCSBN 2026 test plan (effective 2026-04-01 through 2029-03-31): eight Client Needs subcategories at the published planning midpoints, 259 objectives. Built the app-side disclaimer gate, so the per-course acknowledgement the backend already enforced can actually be cleared by a learner.
- REQ-021: Added all eleven currently offered AWS certifications as courses (Cloud Practitioner, AI Practitioner, Solutions Architect Associate, Developer Associate, CloudOps Engineer Associate, Data Engineer Associate, Machine Learning Engineer Associate, Solutions Architect Professional, DevOps Engineer Professional, Security Specialty, Advanced Networking Specialty) — 50 exam domains and 1,031 objectives, with domain weightings, passing scores, and question formats read from the official AWS exam guides on 2026-09-18. Each course now links to its taxonomy subcategory and to a versioned credential exam record carrying the objectives URL, the vendor-verification date, and any announced retirement date.
- REQ-020: Added the complete 13-category education taxonomy, all associated subcategories, three content-freshness models, versioned credential/exam records, course alignment fields, freshness reporting, and an authenticated taxonomy API.
