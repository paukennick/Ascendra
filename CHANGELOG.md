# Changelog

## Unreleased

- REQ-023: Fixed mobile sign-out-on-close/lock over-firing. The AppState listener in `mobile/src/auth/AuthContext.tsx` that locks a biometric-enrolled device or fully signs out everyone else treated any "background" transition as a real app close. Android has no separate "inactive" state, so the account screen's photo-library/camera picker and the Google sign-in browser tab (opened via `expo-web-browser` on both iOS and Android) also reported as "background," silently locking or signing out a signed-in user mid-task. Added a 1500ms grace period that cancels itself if the app returns to "active" first, so those in-app flows are absorbed while a genuine close or screen lock -- which lasts far longer -- still locks/signs out exactly as before; a hard OS kill mid-window is still caught by the existing cold-start session check on next launch. Verified with `tsc --noEmit`; needs a manual device/simulator pass before release since this environment has neither.
- REQ-022: Opened the nursing strand of the catalog with the full licensure ladder. Added Healthcare & Nursing as a fourteenth top-level category with ten subcategories, since the existing taxonomy's nearest fit for licensure was Health & Fitness alongside yoga and dance. Widened credential records so a qualification governed by an accreditation standard or a state licence -- rather than a vendor exam code -- can be recorded and kept fresh. Seeded six courses, each behind a disclaimer the learner must accept: NCLEX-RN and NCLEX-PN from the NCSBN 2026 test plans (effective 2026-04-01 through 2029-03-31, carrying NCSBN's own published Client Needs percentages), Certified Nursing Assistant from the federal requirements at 42 CFR 483.152, Practical Nursing (LPN/LVN), Associate Degree Nursing, and BSN structured on the ten Domains of the AACN Essentials 2026 edition. 45 units and 808 objectives in total. Built the app-side disclaimer gate, so the per-course acknowledgement the backend already enforced can actually be cleared by a learner.
- REQ-021: Added all eleven currently offered AWS certifications as courses (Cloud Practitioner, AI Practitioner, Solutions Architect Associate, Developer Associate, CloudOps Engineer Associate, Data Engineer Associate, Machine Learning Engineer Associate, Solutions Architect Professional, DevOps Engineer Professional, Security Specialty, Advanced Networking Specialty) — 50 exam domains and 1,031 objectives, with domain weightings, passing scores, and question formats read from the official AWS exam guides on 2026-09-18. Each course now links to its taxonomy subcategory and to a versioned credential exam record carrying the objectives URL, the vendor-verification date, and any announced retirement date.
- REQ-020: Added the complete 13-category education taxonomy, all associated subcategories, three content-freshness models, versioned credential/exam records, course alignment fields, freshness reporting, and an authenticated taxonomy API.
